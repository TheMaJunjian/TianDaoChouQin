# TianDaoChouQin

天道酬勤，系统面板 —— 一个纯前端的「网文外挂系统」风格个人成长面板。

网文小说里主角总有一块天道酬勤 / 签到面板，可以直观看到自己的成长。本项目复刻了这块面板：
由于系统「检测功能缺失」，宿主需要手动复写各项数据，系统据此生成属性、技能等级、任务进度与调试日志，
并伴随外挂式的弹出提示，营造「这是一个真外挂，只是部分功能还没解锁」的代入感。

## 界面结构：标签页容器

面板不再是电脑端多面板平铺、手机端纵向堆叠，而是统一的**标签页容器**，无论桌面还是移动端都只显示当前标签页：

- **属性**：基础属性置于最上方（宿主称号、体重、学历、天赋、财产、状态、技能、成就），宿主称号也是一项基础属性，
  点击后由自定义弹窗输入；技能列表紧跟在「技能」一行下方，逐条显示具体技能与等级，而不是只显示「共几项」。
  所有 `+` 均为置灰的强化按钮（属性用属性点、技能用成就点），点击只会弹出文字提示——当前功能尚未开放；
  没有属性点 / 成就点时，对应的 `+` 直接隐藏。宿主状态区的主修方向从已有技能中选择，进度即该技能的进度。
  成就区只展示成就列表：每完成一条支线任务，就会自动结算为一枚成就。手机端浏览时，「面板完整度」进度条离开
  可视区域后会自动吸附在屏幕顶部或底部；完整度达到 100% 后不再吸附（它只是初次填写时的引导）。
- **复写**：复写时间段（时间段归属的「技能」直接从已有技能中选择，复写的小时数会即时抬升该技能等级），
  以及数据导入 / 导出 / 重置。
- **结算**：24 小时时间轴、当日覆盖率、个人调试日志（时间正序）、技能统计。当日日志只把**已经过去**的时间
  判定为「时间空洞 / 未闭合」，尚未到来的时段不会被提示。
- **任务**：主线任务（由开发者发布，线索随系统等级更新解锁）、已发布支线任务列表（显示在主线任务下方），
  以及支线任务发布区。
- **提示**：所有系统提示的历史记录，按时间正序排列（弹出提示的同时会写入这里）。

所有数据变更（复写时间段、复写技能、发布 / 提交支线任务、改名等）都会立即刷新全部面板，无需切换标签页。

## 提示系统

所有系统反馈都以弹出式 toast 的形式出现：在屏幕中央浮现，一路上移到可视区域顶部悬停，最后虚化消失，
并同步归档到「提示」标签页。提示由**点击**触发，因此不做任何去重与间隔限制：宿主点击几次，就提示几次。例如：

- 首次打开：「恭喜您获得天道酬勤系统面板！」
- 完成绑定：「宿主称号已更新为「XXX」。系统已绑定。」
- 复写技能：「检测到宿主技能【XXX】，当前等级：熟悉（累计 350 小时）。」

页面上的静态文字提示已全部移除，改为**点击空白区域**时弹出该区域对应的提示窗：点击某张卡片的空白处会给出这块
功能的说明，点击卡片以外的空白处则按点击位置所属的纵向区域给出不同内容（例如点击最底部会提示「数据仅保存在
本机浏览器」）。标签页也不再使用红点与数字角标，有新内容时对应标签只高亮 1 秒。

## 面板华丽度

随着「宿主状态」「基础属性」「技能」「成就」等数据逐步填写完整，面板视觉效果会从朴素逐级过渡到
完整版特效（发光文字、渐变描边、跑马灯标题），属性页会实时显示当前「面板完整度」百分比。

## 技能等级（一万小时定律）

技能按累计投入小时数自动换算等级：

| 等级 | 最低小时数 | 状态 |
| --- | --- | --- |
| 了解 | 0 | 可用 |
| 入门 | 20 | 可用 |
| 熟悉 | 300 | 可用 |
| 掌握 | 1000 | 可用 |
| 精通 | 5000 | 可用 |
| 宗师 / 圆满 / 神通 | 10000+ | 可见但不可选，受系统等级限制 |

技能复写支持「按等级复写」（自动折算为该等级门槛小时数）或「按小时复写」（自动计算当前等级）。
等级下拉框会完整展示宗师 / 圆满 / 神通三项，但选中后会被系统还原并弹窗提示「宿主技能超过当前系统等级限制」；
累计突破一万小时的技能不会在列表里直接铺开限制说明，而是显示一个 `[!]`，宿主点击后才弹出提示窗。
技能列表显示在「基础属性」的技能一行下方，并做了着重高亮；技能的累计小时 = 手动复写的基准小时 + 复写时间段中
归属该技能的时长，因此主修方向选定已有技能后进度不会从零开始。

## 任务系统与系统等级

- **主线任务**：由开发者在代码中发布（对所有宿主生效），随系统等级（`APP_VERSION`）更新逐条解锁线索。
  宿主可查看指引（指引内容由开发者在 `MAIN_QUEST_GUIDES` 中自定义，留空时提示「暂无提示」）、接受、提交任务；提交后触发「系统正在升级…… → 系统升级完成 → 系统已升级到第 X 版」的提示序列，
  奖励属性点，并将宿主本地系统等级从 `0.1` 推进为 `0.1001`、`0.1002` ……（小数点后第一位由开发者版本控制，
  后续三位记录宿主在主线任务上的完成进度）。
- **支线任务**：由宿主自行发布标题、描述与奖励（属性点 / 贡献点），自行接受、自行提交，系统不校验真实完成情况，
  一切全凭宿主本心。发布后立刻出现在「已发布支线任务」中；提交完成后奖励直接计入属性点与贡献点，
  并自动结算为一枚成就（成就点 = 属性点奖励 + 贡献点奖励）——支线任务完成即成就，因此属性页不再提供成就录入区。

## 数据安全与异常检测彩蛋

- 宿主的每一次操作都会自动保存到浏览器 `localStorage`，代码更新不会覆盖或影响本地数据。
- 支持一键导出 / 导入完整 JSON 数据备份，便于换设备或清理浏览器前迁移。
- 面板会为关键数值（属性点、贡献点、成就点、任务进度）计算一份简单签名；如果检测到这些数值被绕过
  面板直接篡改（例如手动编辑 `localStorage`），会弹出彩蛋警告：「检测到数据异常，世界毁灭倒计时：100」，
  并提供「时间静止」（暂停倒计时，5 秒后自动点击「加速」）与「加速」（瞬间跨越到负数并继续递减，纯属整蛊）两个按钮。

## 使用

直接用浏览器打开 `index.html` 即可，无需构建与后端。数据保存在浏览器 `localStorage`，
清除浏览器数据会丢失记录，请定期在「复写」标签页导出备份。

复写记录使用开始日期、开始时间、结束日期、结束时间四个字段，结束时间填 `00:00` 时请将结束日期设为次日。
跨天记录会自动切片显示在经过的每一天日志中；如果新记录与旧记录重叠，确认「更正」后会裁剪旧记录被覆盖的区间，并保留未覆盖部分。

## 文件

- `index.html` — 标签页容器结构（属性 / 复写 / 结算 / 任务 / 提示）
- `styles.css` — 系统面板风格样式，含标签页、弹出提示、面板华丽度分级、异常检测彩蛋样式
- `app.js` — 状态管理、提示系统、任务系统、技能等级换算、时间账本与统计逻辑
