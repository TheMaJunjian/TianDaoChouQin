# TianDaoChouQin

天道酬勤，系统面板 —— 一个纯前端的「时间账本 / 个人调试日志」面板。

网游小说里主角有天道酬勤面板，可以直观看到自己的进步。本项目复刻了这块面板：
由于「检测模块丢失」，需要宿主手动录入每一段时间做了什么，系统据此生成个人日志，
并按一万小时定律给出可视化进度条。

## 功能

- **时间段录入**：日期 + 开始 + 结束 + 分类 + 事项 + 等级（INFO / TRAIN / WARN / ERROR），自动校验时间倒置与时间段重叠。
- **每日时间轴**：24 小时进度条式时间线，并计算当日覆盖率；未填满时提示剩余「时间空洞」。
- **个人日志**：程序调试日志风格（`[时间] [等级] 内容`），自动补出未填写时段的 WARN 空洞行，可复制。
- **一万小时进度条**：设定主修方向后，按分类累计时长换算 10000 小时进度百分比。
- **分类统计**：全部记录按分类汇总时长。
- **数据导出**：一键导出 JSON 备份。

## 使用

直接用浏览器打开 `index.html` 即可，无需构建与后端。数据保存在浏览器 `localStorage`，
清除浏览器数据会丢失记录，请定期导出备份。

结束时间填 `00:00` 表示当日 24:00。跨夜的时间段请拆成两条记录（例如 23:00-00:00 与次日 00:00-07:00）。

## 文件

- `index.html` — 面板结构
- `styles.css` — 系统面板风格样式
- `app.js` — 记录、日志生成、统计逻辑
