# TianDaoChouQin

天道酬勤，系统面板 —— 一个纯前端的「网文外挂系统」风格个人成长面板。

网文小说里主角总有一块天道酬勤 / 签到面板，可以直观看到自己的成长。本项目复刻了这块面板：
由于系统「检测功能缺失」，宿主需要手动录入各项数据，系统据此生成属性、技能等级、任务进度与调试日志，
并伴随外挂式的弹出提示，营造「这是一个真外挂，只是部分功能还没解锁」的代入感。

## 界面结构：标签页容器

面板不再是电脑端多面板平铺、手机端纵向堆叠，而是统一的**标签页容器**，无论桌面还是移动端都只显示当前标签页：

- **属性**：宿主状态（今日/累计修行时长、一万小时进度）、基础属性（体重、学历、天赋、财产、宿主状态）、技能、成就。
  每个基础属性右侧都有一个灰色 `+`，用于「属性强化」——点击会提示系统等级不足、功能缺失，营造「未来可期」的悬念。
- **录入**：录入时间段（沿用原有的时间账本录入表单），以及数据导入 / 导出 / 重置。
- **时间轴**：24 小时时间轴、当日覆盖率、个人调试日志、分类统计。
- **任务**：主线任务（由开发者发布，线索随固件版本更新解锁）与支线任务（宿主自行发布 / 接受 / 提交）。
- **提示**：所有系统提示的历史记录（弹出提示的同时会写入这里，短时间内的重复提示只会计数、不会刷屏）。

## 提示系统

所有系统反馈都以「叮，……」弹出式 toast 的形式出现（几秒后自动消失），并同步归档到「提示」标签页，
短时间内完全相同的提示不会重复弹出，只在日志里累加次数。例如：

- 首次打开：「叮，恭喜您获得天道酬勤系统面板！」
- 完成绑定：「叮，宿主称号已更新为「XXX」。系统已绑定。」
- 录入技能：「叮，检测到宿主技能【XXX】，当前等级：熟悉（累计 350 小时）。」

## 面板华丽度

随着「宿主状态」「基础属性」「技能」「成就」等数据逐步填写完整，面板视觉效果会从朴素逐级过渡到
完整版特效（发光文字、渐变描边、跑马灯标题），属性页会实时显示当前「面板完整度」百分比。

## 技能等级（一万小时定律）

技能按累计投入小时数自动换算等级：

| 等级 | 最低小时数 | 状态 |
| --- | --- | --- |
| 了解 | 0 | 可用 |
| 入门 | 20 | 可用 |
| 熟悉 | 300 | 可用 |
| 掌握 | 1000 | 可用 |
| 精通 | 5000 | 可用 |
| 宗师 / 圆满 / 神通 | 10000+ | 功能缺失，需完成主线任务解锁 |

技能录入支持「按等级录入」（自动折算为该等级门槛小时数）或「按小时录入」（自动计算当前等级），
两者保持联动，方便宿主持续追踪量化进度。

## 任务系统与版本号

- **主线任务**：由开发者在代码中发布（对所有宿主生效），随固件版本（`APP_VERSION`）更新逐条解锁线索。
  宿主可查看指引、接受、提交任务；提交后触发「系统正在升级…… → 系统升级完成 → 系统已升级到第 X 版」的提示序列，
  奖励属性点，并将宿主本地版本号从 `0.1` 推进为 `0.1001`、`0.1002` ……（小数点后第一位由开发者版本控制，
  后续三位记录宿主在主线任务上的完成进度）。
- **支线任务**：由宿主自行发布标题、描述与奖励（属性点 / 贡献点），自行接受、自行提交，系统不校验真实完成情况，
  一切全凭宿主本心。奖励直接计入属性点与贡献点。

## 数据安全与异常检测彩蛋

- 宿主的每一次操作都会自动保存到浏览器 `localStorage`，代码更新不会覆盖或影响本地数据。
- 支持一键导出 / 导入完整 JSON 数据备份，便于换设备或清理浏览器前迁移。
- 面板会为关键数值（属性点、贡献点、成就点、任务进度）计算一份简单签名；如果检测到这些数值被绕过
  面板直接篡改（例如手动编辑 `localStorage`），会弹出彩蛋警告：「叮，检测到数据异常，世界毁灭倒计时：100」，
  并提供「时间停止」（暂停倒计时）与「加速」（瞬间跨越到负数并继续递减，纯属整蛊，短时间内请勿连续点击）两个按钮。

## 使用

直接用浏览器打开 `index.html` 即可，无需构建与后端。数据保存在浏览器 `localStorage`，
清除浏览器数据会丢失记录，请定期在「录入」标签页导出备份。

结束时间填 `00:00` 表示当日 24:00。跨夜的时间段请拆成两条记录（例如 23:00-00:00 与次日 00:00-07:00）。

## 文件

- `index.html` — 标签页容器结构（属性 / 录入 / 时间轴 / 任务 / 提示）
- `styles.css` — 系统面板风格样式，含标签页、弹出提示、面板华丽度分级、异常检测彩蛋样式
- `app.js` — 状态管理、提示系统、任务系统、技能等级换算、时间账本与统计逻辑
