# TianDaoChouQin

天道酬勤，系统面板 —— 一个纯前端的「网文外挂系统」风格个人成长面板。

网文小说里主角总有一块天道酬勤 / 签到面板，可以直观看到自己的成长。本项目复刻了这块面板：
由于系统「检测功能缺失」，宿主需要手动复写各项数据，系统据此生成属性、技能等级、任务进度与调试日志，
并伴随外挂式的弹出提示，营造「这是一个真外挂，只是部分功能还没解锁」的代入感。

## 界面结构：标签页容器

面板不再是电脑端多面板平铺、手机端纵向堆叠，而是统一的**标签页容器**，无论桌面还是移动端都只显示当前标签页：

- **属性**：基础属性置于最上方（宿主称号、体重、修为、天赋、财产、状态、技能、成就），宿主称号也是一项基础属性，
  点击后由自定义弹窗输入；技能列表紧跟在「技能」一行下方，逐条显示具体技能与等级，而不是只显示「共几项」。
  强化按钮按属性重要度和技能目标等级消耗属性点 / 成就点（体重 1 点、财产 100 点、天赋 500 点；技能等级成本逐级提升）；点数足够时显示置灰的 `+`，点数不足时直接隐藏。
  强化效果本身仍在开发中，点击可用的 `+` 会提示当前模块暂未开放及所需点数。宿主状态区的主修方向从已有技能中选择，进度即该技能的进度。
  成就区只展示成就列表：每完成一条支线任务，就会自动结算为一枚成就。手机端浏览时，「宿主信息完整度」进度条离开
  可视区域后会始终吸附在当前可视区域底部；完整度达到 100% 后不再吸附（它只是初次填写时的引导）。
  手机浏览器中，三组特殊输入区域统一参与点击后的滚动处理：技能表单按当前控件到提交按钮计算；「记录」页分为「开始日期」到「结束时间」的日期 / 时间组，
  以及「技能」「作为」「日志等级」到「写入日志」按钮的记录组；支线表单按当前控件到提交按钮计算。
  键盘定位以原生滚动为主：点击后和可视区域尺寸变化时使用 `scrollIntoView`，并在点击后 350 毫秒重新读取尺寸，再补一次原生滚动。整组能放入可视区域时定位到提交按钮；记录组整体放不下时，只要当前控件到写入按钮及浮动条间距仍能放下，也定位到写入按钮，否则定位到当前控件。根据浮动条是否显示保留间距。新点击、手动滑动或离开页面会取消上一轮延迟滚动。
  记录组定位到写入按钮后，会立即核对按钮相对于视觉视口底部的实际位置；若原生滚动仍未留足间距，只向上补滚缺少的距离，不新增等待或改变属性、任务表单的滚动方式。
  通过 viewport 的 `interactive-widget=resizes-content` 请求浏览器在键盘弹出时同步缩小布局区域，使底部固定浮动条随页面可用高度变化；页面底部固定保留 64 像素滚动余量，覆盖浮动条和按钮的安全间距。
- **记录**：记录时间段（技能可不选；选择已有技能时，记录的小时数会即时抬升该技能等级），
  以及数据导入 / 导出 / 重置。
  写入按钮是一个整体：左侧四分之三为「写入日志」，右侧四分之一为「备注」。备注使用「作为」中的内容，记录点击时刻，
  不改变起止时间、所选技能或日志等级，初次保存不参与时间与技能结算；仅清空已保存的内容。
- **结算**：24 小时时间轴、当日覆盖率、个人调试日志（时间正序）、同级的备注区、技能 / 日志等级统计。备注区提供「未完成 / 已完成 / 回收站」筛选，每个分类都显示所有日期的备注，按记录时间正序排列并显示条数，不受日期导航影响；复制和批量移入回收站针对当前分类。
  点击整条未完成或已完成备注（包括时间、文字和条目内空白；也可用键盘 Enter / 空格选择）会弹出修改窗口，蓝色选择框覆盖整条备注；右上角操作按钮独立处理。修改支持多行文字、保存与取消，保留原记录时间、完成状态和已计入的技能小时，内容不能为空；其他页面同时修改同一备注时会先确认覆盖，已被删除或移入回收站的备注不会被编辑操作重新写回。
  未完成备注右上角从左到右为 `[x]` 删除与 `[✓]` 完成：点击对勾后选择已有技能、填写正数小时（支持小数，单次最多 50000 小时），确认后移入「已完成」，立即更新技能累计小时、等级和主修进度，同一备注只计入一次。完成记录独立保存，删除、恢复或彻底删除备注都会保留已计入的技能小时；刷新和重复导入也不会重复结算。完成备注不会创建时间段或改变时间轴覆盖率。
  叉号先将备注移入回收站；回收站内支持恢复、单条复制备注文字与确认后彻底删除，也可确认后清空回收站。恢复的已完成备注会回到「已完成」。个人日志同样提供回收站：单条删除和清空当日会保留日志，供查阅原记录和确认后彻底删除；跨天日志只移入所选日期的片段，其余日期保留。回收站日志不计入时间与技能统计。
  新日志覆盖旧时段时，被覆盖的旧片段会进入回收站；直接编辑日志会保存编辑前的完整版本，导入合并或覆盖时也会保留原有日志被替换的部分及原回收站。回收站中会显示移入原因，每条日志提供「复制」按钮，可复制起止时间、内容、技能、时长、日志等级及原复写时间（如有）。个人日志回收站仅供查阅、复制与彻底删除，需要调整时由用户参照旧记录在「记录」页手动填写或修改。
  两类回收站及备注完成记录随完整数据备份导入 / 导出，合并时检查完成记录的技能、小时数和备注删除状态冲突。时间轴上的备注线仍与所选日期对应，不显示回收站中的备注。
  时间轴内的金色备注线随缩放范围重新定位，始终对齐备注的实际时间，范围外的备注线不显示。拖动三角游标时实时缩放，向左或向右均可调整范围；游标、圆点和备注线统一按当前可见刻度定位，缩放范围与游标所选时刻分别保存。吸附到备注时，游标和圆点停在当前备注线上，不将备注时刻重新作为缩放边界，也不会跳回全天比例的位置。继续拖动 10 像素可越过吸附点并恢复实时缩放；松手只保存已显示的范围和游标位置，双击时间尺或下方时间刻度可恢复全天。小号金色圆点默认隐藏；滑块吸附到备注时变为金色，对应圆点始终显示在该滑块下方，鼠标移开或失去焦点也会保留，点击可查看备注；离开备注时刻后圆点隐藏。两个滑块分别吸附到备注时，两个圆点都会保留，当前操作的圆点优先显示在相邻圆点上方；缩放使另一个已吸附的备注线移动时，游标与圆点也跟随同一时刻移动。日志吸附点仍使用日志时间段的中间时刻。圆点的透明点击范围向两侧和下方扩大，与三角滑块的拖动区域分开。日志悬浮提示优先显示在条目上方，上方空间不足时移至下方，并避开滚动框和屏幕边界。
  成功写入日志或备注后，「结算」标签会高亮 1 秒。当日日志只把**已经过去**的时间
  判定为「时间空洞 / 未闭合」，尚未到来的时段不会被提示。
- **任务**：主线任务（由开发者发布，完成线索后解锁系统等级）、已发布支线任务列表（显示在主线任务下方），
  以及支线任务发布区。
- **提示**：所有系统提示的历史记录，按时间正序排列（弹出提示的同时会写入这里）。

所有数据变更（记录时间段、记录技能、发布 / 提交支线任务、改名等）都会立即刷新全部面板，无需切换标签页。

## 提示系统

所有系统反馈都以弹出式 toast 的形式出现：在屏幕中央浮现，一路上移到可视区域顶部悬停，最后虚化消失，
并同步归档到「提示」标签页。提示由**点击**触发，因此不做任何去重与间隔限制：宿主点击几次，就提示几次。例如：

- 首次打开：「恭喜您获得天道酬勤系统面板！」
- 完成绑定：「宿主称号已更新为「XXX」。系统已绑定。」
- 记录技能：「检测到宿主技能【XXX】，当前等级：熟悉（累计 350 小时）。」

页面上的静态文字提示已全部移除，改为**点击空白区域**时弹出该区域对应的提示窗：点击某张卡片的空白处会给出这块
功能的说明，点击卡片以外的空白处则按点击位置所属的纵向区域给出不同内容（例如点击最底部会提示「数据仅保存在
本机浏览器」）。标签页也不再使用红点与数字角标，有新内容时对应标签只高亮 1 秒。

## 面板华丽度

随着「宿主状态」「基础属性」「技能」「成就」等数据逐步填写完整，面板视觉效果会从朴素逐级过渡到
完整版特效（发光文字、渐变描边、跑马灯标题），属性页会实时显示当前「宿主信息完整度」百分比。

## 技能等级（一万小时定律）

技能按累计投入小时数自动换算等级：

| 等级 | 最低小时数 | 状态 |
| --- | --- | --- |
| 了解 | 20 | 可用 |
| 入门 | 300 | 可用 |
| 熟悉 | 1000 | 可用 |
| 掌握 | 5000 | 可用 |
| 精通 | 10000 | 可用 |
| 宗师 | 100000 | 可见但不可选，受系统等级限制 |
| 圆满 | 2000000 | 可见但不可选，受系统等级限制 |
| 神通 | 10000000 | 可见但不可选，受系统等级限制 |

记录技能支持「按等级记录」（自动折算为该等级门槛小时数）或「按小时记录」（自动计算当前等级）。属性页的录入字段保持单行外观，使用文本区避开 Chrome 的密码、支付与地址填充入口，体重和投入小时保留数字键盘与数值校验。
等级下拉框会完整展示宗师 / 圆满 / 神通三项，但选中后会被系统还原并弹窗提示「宿主技能超过当前系统等级限制」；
累计突破一万小时的技能不会在列表里直接铺开限制说明，而是显示一个 `[!]`，宿主点击后才弹出提示窗。
技能列表显示在「基础属性」的技能一行下方，并做了着重高亮；技能的累计小时 = 手动复写的基准小时 + 有效时间记录中归属该技能的时长 + 备注完成时计入该技能的小时，
因此主修方向选定已有技能后进度不会从零开始。不指定技能的时间段不会计入任何技能，而会按日志等级计入结算统计。

## 任务系统与系统等级

- **主线任务**：由开发者在代码中发布（对所有宿主生效），完成主线线索后解锁对应的系统等级。主线任务及线索的理论总数量固定为 `TREE(3)`，当前代码中展示的线索只是已发布部分，不能将已发布线索数量当作主线总数。
  宿主可查看指引（指引内容由开发者在 `MAIN_QUEST_GUIDES` 中自定义，留空时提示「暂无提示」）、领取、提交任务；完成线索后触发「系统正在升级…… → 系统升级完成 → 系统已升级到第 X 版」的提示序列，
  奖励属性点，并将宿主本地系统等级从 `0.1` 推进为 `0.1001`、`0.1002` ……（小数点后第一位由开发者版本控制，
  后续三位记录宿主在主线任务上的完成进度）。主线可视化进度最高显示为 `99%`，已发布线索全部完成也不代表 `TREE(3)` 总量完成。已发布线索全部完成后，点击任意属性或技能强化入口都会追加提示系统正在寻找新的主线线索，因为强化模块需要更高系统等级才能解锁。
- 移动端浮动进度条按优先级显示：宿主信息完整度未满时显示宿主信息完整度；其满后显示未完成的支线任务进度；支线任务全部完成后显示主线任务进度。
- **支线任务**：由宿主自行发布标题、描述与奖励（属性点 / 成就点），自行领取、自行提交，系统不校验真实完成情况，
  一切全凭宿主本心。发布后立刻出现在「已发布支线任务」中；提交完成后，贡献点按属性点与成就点之和结算，
  并自动结算为一枚成就——支线任务完成即成就，因此属性页不再提供成就录入区。已完成的支线任务可以再次领取和提交，任务卡片会显示累计完成次数，每次重复完成都会再次结算奖励并新增一枚成就。
  任务名称与奖励字段使用单行文本区，避开密码、支付与地址填充入口；奖励保留数字键盘、整数换算和负数扣减，名称与奖励字段按回车可发布任务，描述仍支持多行。

## 数据安全与异常检测彩蛋

- 宿主的每一次操作都会即时保存到浏览器 `localStorage`，并同步写入独立备份；刷新、关闭浏览器、重启设备或重新访问同一网址时会从同一份数据恢复。
- 同一网址的多个标签页共享唯一系统数据，任一标签页的改名、记录、任务和导入结果会同步到其他标签页。
- 支持一键导出 / 导入完整系统数据备份，便于换设备或清理浏览器前迁移。
- 导入前可选「兼容扩充」或「覆盖当前数据」。兼容扩充会保留双方独有数据并去重，列出属性、点数余额、技能、任务、备注及时间记录冲突，可逐项选择或批量处理；全部处理后才可确认。时间段重叠时保留未覆盖部分，原有日志被替换的片段进入回收站，跨天记录同样适用。点数余额只选择一份，不重复相加或再次发放任务奖励。覆盖模式会明确提示当前数据将被替换，并将原有日志被替换或移除的部分存入个人日志回收站；检查和取消不会更改当前记录。
- 新备份使用日期、时分秒、毫秒和随机标识组成文件名。支持文件夹选择的浏览器会在选定文件夹内检查重名并继续更名；其他浏览器使用独立文件名下载。
- 桌面版 Chrome / Edge 等支持直接操作文件的浏览器另提供「更新已有文件」：先选择并读取原备份，保留文件独有的数据，列出冲突；只有没有冲突才允许确认更新。写入前及提交前会复查原文件，检查后被其他程序改动则取消更新。有冲突时先用兼容扩充处理，再另存新文件。其他浏览器仍可导入和下载新备份。
- 面板会为关键数值（属性点、贡献点、成就点、任务进度）计算一份简单签名；如果检测到这些数值被绕过
  面板直接篡改（例如手动编辑 `localStorage`），会弹出彩蛋警告：「检测到数据异常，世界毁灭倒计时：100」，
  并提供「时间静止」（暂停倒计时）与「加速」（瞬间跨越到负数并继续递减，纯属整蛊）两个按钮。

## 使用

直接用浏览器打开 `index.html` 即可，无需构建与后端。数据保存在浏览器本地存储，
清除浏览器数据、使用无痕模式或浏览器主动清理站点数据仍可能导致记录丢失，请定期在「记录」标签页导出备份。

复写记录使用开始日期、开始时间、结束日期、结束时间四个字段，结束时间填 `00:00` 时请将结束日期设为次日。
跨天记录会自动切片显示在经过的每一天日志中；如果新记录与旧记录重叠，确认「更正并保留旧记录」后会将旧记录被覆盖的区间移入回收站，并保留未覆盖部分。需要调整旧记录时，可在「结算 → 个人日志 → 回收站」查阅或复制内容，再到「记录」页手动填写或修改。

## 文件

- `index.html` — 标签页容器结构（属性 / 记录 / 结算 / 任务 / 提示）
- `styles.css` — 系统面板风格样式，含标签页、弹出提示、面板华丽度分级、异常检测彩蛋样式
- `app.js` — 状态管理、提示系统、任务系统、技能等级换算、时间账本与统计逻辑
- `backup.js` — 备份去重、冲突合并、独立文件名及受保护的文件写入
- `tests/backup.test.js` — 运行 `node --test tests/backup.test.js` 验证合并及文件保护；`data/` 中存在两份本地测试备份时，也会验证双向合并为 598 条时间记录、18 条备注，以及重复导入不会增加记录。个人备份文件通过 `.gitignore` 排除，不随代码公开。
